# 🍃 GreenSync

**Plataforma Inteligente para Gestão e Monitoramento de Condomínios Sustentáveis**[cite: 1]

## 📖 Sobre o Projeto
O GreenSync é uma plataforma web de gestão participativa voltada para condomínios residenciais[cite: 1]. O projeto visa automatizar o monitoramento de consumo de água e energia e engajar os moradores na redução do impacto ambiental, alinhando-se ao Objetivo de Desenvolvimento Sustentável 11 (ODS 11) da ONU[cite: 1].

## ✨ Funcionalidades
* **Leitura Automatizada (OCR):** Extração automatizada de dados de consumo e valor a partir de faturas de água e energia[cite: 1].
* **Dashboards Interativos:** Exibição de gráficos com o histórico de consumo dos moradores[cite: 1].
* **Gamificação e Comunidade:** Atribuição de pontos por consumo adequado, mural colaborativo, votações e rankings dinâmicos em tempo real[cite: 1].
* **Gestão de Resíduos:** Consulta a um guia inteligente que classifica resíduos e orienta sobre o descarte correto[cite: 1].
* **Alertas Inteligentes:** Geração de notificação imediata caso o consumo mensal ultrapasse 30% da média histórica[cite: 1].

## 🚀 Tecnologias Utilizadas
* **Frontend:** HTML, CSS, JavaScript e Chart.js para a construção de interfaces responsivas e dashboards iterativos[cite: 1].
* **Backend:** Node.js e Express para a estruturação da API RESTful[cite: 1].
* **Banco de Dados:** MySQL para o armazenamento relacional de leituras e perfis de forma segura[cite: 1].
* **Comunicação em Tempo Real:** Socket.IO para o envio de alertas de anomalia e atualização de rankings[cite: 1].
* **Processamento de Imagem:** Tesseract.js integrado para viabilizar a extração automática de texto (OCR)[cite: 1].
* **Prototipagem e Design:** Figma para a elaboração de wireframes e validação da experiência do usuário[cite: 1].
